# 제목
[M5] 저장·오류 안내·다듬기

## 목적
마지막 입력을 브라우저에 저장해 새로 고쳐도 남기고, JSON 백업과 오류 안내를 더해 쓰기 쉽게 다듬는다.

## 완료 기준
| 항목 | 사람이 화면에서 볼 것 |
|---|---|
| S3 보강 | 지번이 빈 줄 외에 열 개수가 맞지 않는 줄을 넣으면, 그 줄도 '확인 필요'에 줄 번호와 사유로 나온다. 빈 입력으로 '대조'를 누르면 안내 문구가 나온다. |
| 저장(AC5) | 입력 후 새로 고쳐도 마지막 입력이 남아 있다. 저장은 localStorage 키 `m5_permit_filter` 하나만 쓴다. |
| 백업(AC6) | '백업 내보내기'로 받은 JSON을 '가져오기'로 넣으면 같은 입력이 복원된다. |
