# 제목
[M5] 화면 틀과 표본 넣기

## 목적
`tools/m5_permit_filter.html` 파일 하나에 ① 입력 화면과 ② 결과 화면의 틀을 만들고, 표본을 붙여 넣어 줄 수를 확인할 수 있게 한다. 대조(판정)는 이 Issue에서 하지 않는다.

## 완료 기준
| 항목 | 사람이 화면에서 볼 것 |
|---|---|
| S1 준비 | `data/m5_sample.txt`의 변화 지점 10줄과 인허가 6줄을 각 칸에 붙여 넣으면 '변화 지점 10건 · 인허가 6건'이 입력 화면에 보인다. |
| 화면 전환 | '대조' 버튼을 누르면 결과 화면 틀이 열리고 '입력으로 돌아가기'로 돌아온다. 결과 칸은 비어 있어도 된다. |
| 형태 | 파일을 더블클릭해 열어도 같은 화면이 뜬다. 외부 주소·fetch·라이브러리가 없다. |
