# 제목
[M5] MVP 판정 — 허가 대조 필터링

## 목적
변화 지점의 지번을 인허가 목록의 지번과 맞춰 보고, 허가 없음·허가 확인·확인 필요로 나눠 결과 화면에 보여 준다. 지번이 같으면 허가가 있는 것으로 본다 `[가정]`.

## 완료 기준
| 항목 | 사람이 화면에서 볼 것 |
|---|---|
| S1 | 표본을 넣고 '대조'를 누르면 허가 없음·허가 확인·확인 필요 건수가 보이고 합이 10건이다(PRD 5절 S1의 건수와 대조). |
| S2 | 인허가 목록에 지번이 있는 지점은 '허가 없음'에 나오지 않고 '허가 확인'에 인허가 번호와 함께 나온다. 본번만 같은 지번(부번이 다름)은 같은 필지로 보지 않는다. |
| S3 | 지번이 빈 줄은 '확인 필요'에 줄 번호·사유와 함께 나오고 합계에서 빠지지 않는다. |

## 범위 밖

- 저장·백업·오류 안내 다듬기(m5_3)
- 사진 비교 탐지, 지도 표시·위험도 정렬
