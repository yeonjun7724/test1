# 개인 레포 사용 규칙 (1쪽)

이 레포는 AX 심화과정의 개인 작업 공간입니다. 운영사 GitHub 조직이 소유한 비공개 레포이며, 본인은 쓰기 권한, 강사는 관리 권한을 가집니다. 모든 실습은 Claude Code 클라우드 세션에서 이 레포 하나만 열고 진행합니다.

## 2. 지켜 주실 것

1. `inputs/`와 `.claude/skills/hanbit-prd-interview/`는 고치지 않습니다. 결과는 늘 새 파일로 만듭니다.
2. 이 레포에 올린 것은 외부 클라우드(Anthropic 클라우드 VM과 GitHub)에 올린 것입니다. 가상 자료만 넣습니다. M5 웹앱은 GitHub Pages로 배포되어 **누구나 주소로 열 수 있습니다.**
3. 실명·연락처·실제 내부 자료·실제 사업 자료·비밀번호는 넣지 않습니다.
4. 교육 레포가 아닌 다른 레포를 클라우드 세션에 붙이지 않습니다. 한 세션에는 레포 1개만 엽니다.
5. AI 결과는 판단을 확정하지 않습니다. 법규 적합·안전 판정·보상·계약금액·당첨·자격은 담당자가 확인합니다.
6. 모든 실습은 본인 Claude 계정(교육용 Team 좌석)으로 합니다. 사용량 한도로 멈추면 손을 들고, 강사 안내가 있을 때만 대체 경로(Upstage Solar)로 이어 갑니다.

## 3. 커밋과 제출

- git 명령어는 쓰지 않습니다. Claude에게 우리말로 "커밋 메시지는 [M1] 회의록과 근거표로 커밋해 줘"처럼 지시합니다.
- 단계가 끝날 때, 휴식·점심 전, 블록이 끝날 때마다 커밋합니다. 오래 쉬면 세션 작업 공간이 정리될 수 있습니다.

> PR 흐름: ① 세션에 지시하면 세션이 자기 브랜치에 올립니다 → ② 세션 화면 **Create PR** → GitHub 웹 PR 화면 **Merge** → ③ main에서 파일 확인 → ④ 블록 끝 제출 = 열린 PR을 모두 병합한 main. 되돌리기 = 병합된 PR 화면 **Revert** → 새 PR → **Merge**.

- PR은 세션 화면의 **Create PR** 버튼으로 만듭니다. 버튼 위치는 교육 전 실측으로 확인해 강사 화면으로 안내합니다.
- M4는 PR이 두 번입니다. 먼저 CLAUDE.md·Skill 정리 PR을 병합하고, **새 세션**을 열어 다음 주 자료를 처리합니다. 새 세션은 main을 새로 가져오므로 정리본이 들어 있습니다. CLAUDE.md를 고치는 PR이 동시에 두 개 열리지 않게 합니다.
- M5는 **Issue 하나 = 새 세션 하나 = PR 하나**입니다. Issue는 GitHub 웹 **Issues** 탭에서 본인이 등록하고, PR 본문 첫 줄에 `Closes #Issue번호`를 쓰면 병합할 때 Issue가 닫힙니다. 병합된 main의 `tools/m5_*.html`은 1~2분 뒤 Pages 주소로 열립니다(Pages는 운영 측이 미리 켜 둡니다).

| 대상 | 커밋 머리 | 제출(main 기준) |
|---|---|---|
| 환경 세팅 `docs/setup_check.md` · `docs/prd_memo.md` | `[세팅]` | 월 환경 세팅 블록 끝 |
