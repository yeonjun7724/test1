## 2. 멈춘 이유 — 접수일 표기 (규칙에 없음)

- 대상: 데이터 행 5(HA-050, 설비·긴급·접수), 행 12(HA-057, 전기·긴급·완료), 행 22(HA-067, 전기·긴급·완료).
- week1 규칙에는 접수일 표기 기준이 없다. `scripts/aggregate.py`의 `check_date`도 "접수일 규칙이 없으므로 그대로 쓴다"는 자리표시자다.
- 처리 방식에 따라 건수가 달라진다: ① 정규화해 포함(연도 없는 `11-05`는 2026년으로 추정해야 함 — 자료 근거 없음), ② 날짜 확인 필요로 제외(공종·긴급 건수가 줄어듦), ③ 그대로 포함(날짜는 중복 판정 키로만 쓰이며 이 3행은 중복 대상 아님).
- 결정이 필요한 것: 세 표기의 정규화 규칙(예: `.`·`/` → `-`), 연도 없는 `11-05`의 처리, 처리 후 규칙 파일(`rules/aggregation_rules.md`)에 넣을 문구.

## 3. 처리 결과

- 보류 3행: 데이터 행 5 HA-050 `2026.11.03` / 행 12 HA-057 `2026/11/04` / 행 22 HA-067 `11-05`. `excluded_rows.csv`에 `확인 필요(접수일 표기)`로 남김.
- 규칙 파일 갱신: 대상·기준일에 week2 추가, 규칙 5(접수일 표기 → 보류) 추가, `--area-fix` 설명 추가. `aggregate.py`는 접수일 검사와 `--area-fix` 옵션을 추가(week1 재실행 결과는 `outputs/m2/summary.csv`와 동일 확인).
- 집계(`summary.csv`): 정상 34건, 마감 11·창호 6·설비 6·전기 5·방수결로 6, 접수 16·처리중 8·완료 10, 긴급 11, 면적 123.3㎡ / 실측 정정 반영 125.2㎡. 제외 6행(보류 3, 중복 1, 위치 불명 1, 합계 1).
- 대조(`check.md`): 행 번호로 직접 센 값과 전 항목 일치. 검산표 없음.
- 대장: A-L13~A-L23 추가(기존 행 변경 없음). 건수·긴급·미처리는 보류 3행을 뺀 잠정값으로 비고에 표기.
- 정합: `consistency_report.md` 불일치 0건(회의록 5절 기준). 문서 수정은 `impact_list.md` 승인 대기(승인 ☐).
