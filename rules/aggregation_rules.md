# 집계 규칙 (M2 하자접수대장)

적용 대상: `inputs/m2/A-M2-01_하자접수대장_week1.csv` (원본은 읽기만 함)
행 번호: 머리행을 뺀 데이터 행 번호(1부터)

## 검사 순서

앞 규칙에서 제외된 행은 뒤 규칙을 적용하지 않는다. 순서를 바꾸면 결과가 달라지므로 아래 순서를 지킨다.

1. 합계 행 제외 (집계 대상이 아닌 행을 먼저 걷어낸다)
2. 완전 중복 제외 (같은 접수번호는 한 건만 남긴다)
3. 준중복 표시 (번호만 다르고 내용이 같은 행은 지우지 않고 표시한다)
4. 위치코드 표준화 (동-호-공간)
5. 면적 단위 통일 (㎡)
6. 면적 공란 처리
7. 값 범위·형식 검사 (날짜, 구분값, 상태값)
8. 합계 행 대조 (정리 후 값과 원본 합계 행 비교)

## 규칙표

| # | 규칙 | 판정 방법 | 처리 | 기록 위치 |
|---|---|---|---|---|
| 1 | 합계 행 | 접수번호가 `합계`이거나 접수번호가 `HA-숫자` 형식이 아닌 행 | 제외 | excluded_rows.csv |
| 2 | 완전 중복 | 접수번호가 같고 나머지 모든 칸 값도 같은 행. 첫 행만 남김 | 둘째 행부터 제외 | excluded_rows.csv |
| 2a | 접수번호만 같고 내용이 다른 행 | 접수번호는 같은데 다른 칸이 하나라도 다른 행 | 제외하지 않고 보류, 집계 전에 사용자 확인 | run_log.md ({확인 필요}) |
| 3 | 준중복 | 접수번호는 다르고 위치코드(표준화 후)·공종·하자내용이 모두 같은 행 | 포함(둘 다 세되 표시) | run_log.md ({확인 필요: 같은 건인지}) |
| 4 | 위치코드 표기 | 표준형 `NNN-NNNN-공간`과 다른 표기. 동·호·공간을 구분자로 안전하게 나눌 수 있으면 고친다 | 고쳐서 포함 (예: `110동 501호 안방` → `110-501-안방`, `111-603 욕실` → `111-603-욕실`) | run_log.md (원래 값 → 고친 값) |
| 4a | 위치코드 복원 불가 | 구분자가 없어 동·호를 나눌 수 없는 값(`111301`) | 포함, 위치 항목만 {확인 필요: 동·호} | run_log.md |
| 4b | 하자내용 속 다른 세대 정보 | 괄호 등에 다른 호수가 적힌 행(HA-024의 `1104호`) | 포함, 원문 유지. 다른 세대와 연결하지 않음 | run_log.md |
| 5 | 평 단위 | 면적단위가 `평` | 고쳐서 포함: ㎡ = 평 × 3.3058 (소수 둘째 자리 반올림은 합계 단계에서만) | run_log.md (원래 값·단위 → 환산 값) |
| 5a | 알 수 없는 단위 | 면적단위가 `㎡`·`평` 이외 | 제외 | excluded_rows.csv |
| 6 | 면적 공란 | 보수면적과 면적단위가 모두 빈 행 | 건수에는 포함, 면적 합계에는 넣지 않음(0으로 치지 않음) | run_log.md (공란 행 수와 공종) |
| 6a | 면적·단위 불일치 | 한쪽만 비어 있거나 면적이 숫자가 아닌 행 | 제외 | excluded_rows.csv |
| 7 | 형식·값 범위 | 접수일이 `YYYY-MM-DD`가 아니거나 접수일이 대상 주(10-26~10-30) 밖, 긴급구분이 `긴급`/`일반` 이외, 처리상태가 `접수`/`처리중`/`완료` 이외, 면적이 음수이거나 0 | 제외 | excluded_rows.csv |
| 8 | 합계 대조 | 정리 후 건수·면적 합계를 원본 합계 행(44건, 118.1)과 비교 | 일치하지 않으면 차이 원인을 규칙별로 설명 | run_log.md |

## 이번 주 자료에 적용했을 때 예상 결과

사전 점검(데이터 행 44개 + 합계 행) 기준이며, 실제 처리 후 `run_log.md`에서 다시 확인한다.

- 제외: 45번(합계 행), 32번(HA-031 완전 중복) → 건수 43건
- 고쳐서 포함: 위치 2번·21번, 평 단위 8·13·22·26번
- 포함, 확인 필요: 16번(위치), 24번(1104호), 38·40번(준중복, 포함 시 건수는 43건 유지)
- 면적 공란 23개 행(1, 2, 6, 9, 11, 12, 16, 17, 18, 21, 23, 24, 25, 30, 31, 32, 34, 35, 37, 38, 40, 43, 44번): 32번이 규칙 2에서 빠지므로 면적 합계에 영향 없음
- 면적 합계: 원본 118.1은 단위가 섞인 값이고, 평 환산 후 약 144.39㎡

## 파일 형식

`excluded_rows.csv` 열: `행번호, 접수번호, 규칙번호, 사유, 원문(행 전체)`
`run_log.md`: 규칙 번호별 섹션에 `[값 | 출처 파일 | 행 번호 | 처리]` 형식으로 기록한다. 자료에 없는 값은 `{확인 필요: 항목}`으로 남긴다.

## 사용자 확인이 필요한 가정

- 평 → ㎡ 환산 계수 3.3058은 제가 정한 값이며 자료에 근거가 없다.
- 준중복(규칙 3)을 제외하지 않고 포함하는 쪽으로 정했다. 접수번호가 다르면 별개 접수로 보는 보수적 선택이다.
- 접수일 허용 범위(10-26~10-30)는 이번 주 자료에서 읽은 값이다.
